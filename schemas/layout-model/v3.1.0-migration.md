# Layout Data Model File 3.0.0 to 3.1.0

The one migration note of 3.1.0 (ADR 0008 C8; ADR 0010 C1). 3.1.0 is a minor version: it only adds keys.

- A 3.0.0 file becomes a 3.1.0 file by changing its `schema` string to `layout-model/v3.1.0`. No key is renamed,
  moved or removed.
- New under each interlocking: `appliances{}` and `track{}`, the trackplan (`$defs/appliance`, `$defs/trackplan`,
  `$defs/trackSymbol`, `$defs/portRef`), and `geometry` (ADR 0010 §4.10). New under `layout`: `glyphs{}`. New
  under `provenance`: `libraries`. In 3.0.0, `appliances`, `track` and `geometry` were open objects (ADR 0008 C4);
  in 3.1.0 they reject unknown keys.
- A 3.0.0 reader reads a 3.1.0 file by skipping the keys it does not know and reporting each one at info (ADR 0008
  C8: strict writer, lenient reader).
- The KiCad importer writes 3.1.0 whether the placement reader is on or off (`compile_layout.py --geometry`). Without
  the flag, `geometry`, `glyphs` and `libraries` are absent.
